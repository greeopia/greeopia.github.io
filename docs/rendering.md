# 文章内容显示

文章仍然可以从博客园同步，也可以直接写在 `source/_posts/`。
站点统一处理 Markdown 代码围栏和同步得到的 HTML 代码块，不需要手动重写旧文章。

代码块应标明语言，例如：

````markdown
```cmake
# 这是注释，不是文章标题
set(CMAKE_CXX_STANDARD 17)
```
````

常用标签：`cmake`、`makefile`、`c`、`cpp`、`bash`、`powershell`、`json`、`yaml`。
未知语言仍以普通代码显示。代码内的缩进、引号和模板符号保持原样。

行内公式用 `$v = s/t$`，独立公式用双美元符号：

```text
$$
\omega_z = \frac{v_R - v_L}{b}
$$
```

Markdown 公式在构建时生成；同步 HTML 中的公式在浏览器中补充渲染。
公式所需的脚本、样式和字体随站点发布，不依赖额外的 CDN。

验证：`npm test` 检查代码内容保真和公式渲染，`npm run build` 生成静态站点，
`npm run server` 预览桌面和手机布局。代码和长公式在自身区域内横向滚动。
构建时串行写入资源，避免 Windows 首次生成字体目录时的并发创建错误。

站点字数按已发布文章正文的非空白字符统计，不重复计算摘要、代码行号或公式的隐藏文本。
未接入真实访问统计前，不显示浏览器本地计数冒充的“访客”数字。
