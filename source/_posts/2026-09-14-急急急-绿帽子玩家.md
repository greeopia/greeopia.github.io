<h2 id="旋转编码器测速">旋转编码器测速：</h2>
<ul>
<li>B相下降沿+A相低电平 -&gt; 正转</li>
<li>A相下降沿+B相低电平 -&gt; 反转</li>
</ul>
<p>不直接返回count主要是代码可移植性和封装的考虑 另外最好不要在主函数和中断函数里面操作同一个变量 有可能会出现未知bug</p>

<p>为什么 GPIO 使用之前必须开时钟？</p>
<p>因为默认关闭不用的外设时钟可以降低功耗。</p>

<pre><code class="language-c">/* 定时器时基配置：决定 CNT 怎么计数 */
typedef struct
{
    uint16_t TIM_Prescaler;
    // 预分频器 PSC
    // CNT时钟 = 定时器时钟 / (PSC + 1)
	// 0~65535

    uint16_t TIM_CounterMode;
    // 计数模式：向上、向下或中央对齐计数
	// TIM_CounterMode_Up ,TIM_CounterMode_Down
	// TIM_CounterMode_CenterAlignedx (x=1,2,3)

    uint16_t TIM_Period;
    // 自动重装值 ARR
    // 向上计数时：CNT从0数到ARR，然后重新从0开始
	// 0~65535

    uint16_t TIM_ClockDivision;
    // 定时器数字滤波器、死区等模块的时钟分频 -&gt; 滤波器采样时间由当前tim和这个值决定
    // 一般设为 TIM_CKD_DIV1；它不负责CNT的主要分频
	// TIM_CKD_DIV1 ,TIM_CKD_DIV2 ,TIM_CKD_DIV4

    uint8_t TIM_RepetitionCounter;
    // 重复计数器 RCR
    // 主要供高级定时器 TIM1/TIM8 使用，普通场景设为0

} TIM_TimeBaseInitTypeDef;
